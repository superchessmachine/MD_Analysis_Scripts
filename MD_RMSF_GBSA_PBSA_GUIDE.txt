target protein RMSF, GBSA, and PBSA workflow guide
========================================

Purpose
-------
This guide documents the workflow used for the packaged target protein simulations in:

  /Users/ysb/analysis_project

The reusable automation script is:

  /Users/ysb/MD_Analysis_Scripts/md_rmsf_mmpbsa_workflow.py

It handles:

  1. C-alpha RMSF plots comparing apo and ligand-bound simulations.
  2. Last-N-ns RMSF plots.
  3. Quick protein-ligand GBSA with AmberTools MMPBSA.py.
  4. Last-20-ns protein-ligand PBSA with AmberTools MMPBSA.py.

The script was written for packaged trajectory folders that only contain
GROMACS view files, for example:

  apo_monomer/apo_monomer_view.gro
  apo_monomer/apo_monomer_view.xtc
  monomer_ligand_rep1/monomer_ligand_rep1_view.gro
  monomer_ligand_rep1/monomer_ligand_rep1_view.xtc

Why the workflow uses an AmberTools fallback
--------------------------------------------
Native gmx_MMPBSA setup was attempted, but the packaged system does not include
the original GROMACS .top/.itp/.tpr files. gmx_MMPBSA can still generate useful
intermediate receptor and ligand PDB files from the structure and index, but it
fails at tleap for this ligand/disulfide setup.

The script therefore:

  1. Uses gmx_MMPBSA to create receptor/ligand PDB intermediates.
  2. Generates GAFF/AM1-BCC ligand parameters from the extracted ligand PDB.
  3. Detects CYX-SG disulfides automatically from the receptor PDB.
  4. Builds COM/REC/LIG Amber prmtops with tleap.
  5. Strips the trajectory to protein plus ligand.
  6. Runs AmberTools MMPBSA.py for GBSA and/or PBSA.

Because of that fallback, gmx_MMPBSA_ana is not the primary viewer for these
results unless a native COMPACT_gmx_MMPBSA_RESULTS.mmxsa exists. Use the CSV
plotting commands below instead.

Important options
-----------------
Root and input files:

  --root
    Root folder containing the simulation folders.

  --apo-gro / --apo-xtc
    Apo structure and trajectory paths relative to --root.

  --bound-gro / --bound-xtc
    Ligand-bound structure and trajectory paths relative to --root.

RMSF:

  --last-ns 10
    Last-N-ns RMSF window. Default is 10.

Ligand:

  --ligand-resname UNL
    Ligand residue name in the GROMACS files.

  --ligand-charge 1
    Net ligand charge passed to antechamber. Ligand here was treated as +1.

GBSA:

  --run-gbsa
    Enable GBSA.

  --gbsa-interval 5
    Analyze every 5th saved frame.

  --gbsa-startframe / --gbsa-endframe
    Optional manual frame range.

PBSA:

  --run-pbsa
    Enable PBSA.

  --pbsa-last-ns 20
    Last-N-ns PBSA window if --pbsa-startframe is not given.

  --pbsa-interval 5
    Analyze every 5th saved frame.

  --pbsa-startframe / --pbsa-endframe
    Optional manual frame range.

  delta_gas_vs_solv.png

For GBSA, the PB plotting script expects PB column names such as EPB. The GBSA

plotting columns before using the PB plotting script.


About gmx_MMPBSA_ana
--------------------
If a native gmx_MMPBSA run succeeds and produces a compact results file, use:

  conda run -n gmxmmpbsa gmx_MMPBSA_ana -f COMPACT_gmx_MMPBSA_RESULTS.mmxsa

For the current packaged target protein files, native gmx_MMPBSA does not complete the
full topology build, so this file is not produced. Use the MMPBSA.py .dat/.csv
outputs and the plotting workflow above.

Known caveats
-------------
1. The packaged files are view-only .gro/.xtc files, not a full original
   GROMACS simulation package. Results are suitable as a quick interaction
   analysis, not a fully polished production free-energy protocol.

2. The ligand is generated with GAFF/AM1-BCC from the extracted ligand PDB.
   If you have the original ligand mol2/topology from system setup, use that
   for a more faithful analysis.

3. PBSA is slower than GBSA. Keep --pbsa-interval > 1 for quick checks.

4. The script sets GMX_MAXBACKUP=-1 so reruns overwrite GROMACS output files
   instead of creating many #backup# files.

5. The current PBSA settings use inp=1, radiopt=0, istrng=0.150, fillratio=4.0.
   These were chosen as conservative quick settings for the generated Amber
   prmtops and GAFF ligand.
